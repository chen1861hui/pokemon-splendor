# Trainer artwork sources

The cleaned transparent trainer artwork is used for this private fan-made prototype.

- `ash-art.png`: [Ash with Pikachu](https://archives.bulbagarden.net/wiki/File:Ash_with_Pikachu.png), official animation artwork archived by Bulbagarden.
- `ash-xy.svg`: user-provided XY Ash vector artwork, currently used by the trainer selector.
- `brock-art.png`: [Brock and Onix](https://archives.bulbagarden.net/wiki/File:Masters_Brock_Onix.png), Pokémon Masters artwork archived by Bulbagarden.
- `misty-art.png`: [Misty](https://archives.bulbagarden.net/wiki/File:Misty_SM.png), official animation artwork archived by Bulbagarden. Psyduck is composed separately from the local Pokémon artwork.
- `team-rocket-art.png`: [Team Rocket trio](https://archives.bulbagarden.net/wiki/File:Team_Rocket_trio_SM.png), official animation artwork archived by Bulbagarden.

Pokémon character artwork remains the property of its respective rights holders. Confirm licensing before distributing the project publicly.
